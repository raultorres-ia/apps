# Portfolio de Raül Torres

Web estática: abre `index.html` o sirve esta carpeta con un servidor HTTP. No requiere compilación.

## Organización

- `index.html`: contenido y estructura de la web.
- `assets/css/styles.css`: estilos y diseño adaptable.
- `assets/js/script.js`: idiomas y navegación.
- `assets/images/hero/`: fondo de la portada.
- `assets/images/profile/`: fotografía de perfil.
- `assets/images/posters/`: carátulas, nombradas por película. `unfurnished-alternative.png` se conserva como recurso alternativo sin referencia actual en la página.
- `assets/images/certificates/`: premios, nominaciones y certificados.
- `assets/images/partnerships/`: acreditaciones de colaboraciones creativas.
- `assets/images/icons/`: iconos de redes sociales.

Los recursos usan nombres en minúsculas con guiones y rutas relativas. Las rutas de imágenes del CSS se resuelven desde `assets/css/`.
